# Supreme Builder

Crusader Kings III domain construction QoL mod. Version 0.1.0. Supported game version 1.20.*.

Commission builders once across your domain: fill empty holding slots with missing eligible vanilla L1 buildings, or upgrade existing regular lines by one tier. You pay gold at vanilla base costs adjusted by known construction-cost discounts (Architect, lifestyle perks, and other character-level modifiers), and construction completes instantly.

Requires the **Supreme Sovereign** trait (`Supreme_Sovereign`) from the Supreme Sovereign mod (soft dependency — decisions stay hidden if the trait is not present). Enable both in the same playset.

Prefix: `sb_`. Additive only; no `replace_path`. Player-only; AI never uses these decisions.

Canonical working copy (when Windows is online): `Documents/Development/CK3 Mods/sb` (+ outer `sb.mod`). GitHub is source of truth for this ship.
